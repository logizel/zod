## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ATS/aggregator/HN payloads → adapters | Untrusted external JSON/HTML/XML enters through eight listing adapters |
| Adapter → outbound network | Fixed third-party hosts (ATS APIs, aggregator pages, Algolia, RSS) plus the shared browser queue |
| getJobCandidates → learned-board state file | Block-volume JSON state written from observed candidate URLs |
| Signals → logs | Source names, URLs, and titles flow through structured logs |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
