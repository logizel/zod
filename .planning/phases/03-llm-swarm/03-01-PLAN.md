<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env → LLM provider | GROQ_API_KEY / GITHUB_TOKEN cross from env to Authorization header; leak risk in logs and token file |
| provider → router | Untrusted model output (partial JSON, truncated stream) enters the stitcher; parse failures must stay loud |
| router → agent_telemetry | Bucket state written to PocketBase; status transitions drive operator visibility and cool-down scheduling |
| scheduler → gateway | Cool-down timers registered in the single cron registry; mis-registration risks orphaned timers or silent bucket starvation |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Info disclosure | LLM provider keys in logs | high | mitigate | pino REDACT_PATHS includes GROQ_API_KEY/GITHUB_TOKEN/SAMBANOVA_API_KEY; env.parse() fail-fast; keys never persisted in scratchpad rows |
| T-03-02 | Tampering | Truncated/partial JSON verdict accepted | high | mitigate | Stitch validates merged output with JSON.parse; invalid → surface as UNVERIFIED, never route a malformed verdict |
| T-03-03 | Denial of service | Bucket stuck in 60s-COOLDOWN / DAILY-CAP | medium | mitigate | Time-driven recovery (cooldownUntil timestamp, daily-cap resets at UTC midnight); router skips unavailable buckets, never blocks the caller |
| T-03-04 | Denial of service | Orphaned cool-down timers bypassing registry | medium | mitigate | All bucket timers route through packages/scheduler/src/registry.ts (noOverlap + maxRandomDelay); no setInterval in packages/llm |
| T-03-05 | Repudiation | Audit trail lost (which bucket produced verdict) | low | mitigate | LlmRouter.complete() returns `path` listing every bucket attempted; telemetry rows record provider/model/step/status |
</threat_model>
