<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ladder → Tier2 | Overflow engages only after Tier1 exhausts; mis-configured tier gate risks premature Tier2 (rate-limit burn) or no fallback (verdict failure) |
| circuit-breaker → paid | Default-deny paid traffic; mis-configuration risks unauthorized spend (violates zero-cost constraint) |
| priority queue → pool | Curator preemption risks Scout starvation under sustained load; global in-flight cap prevents deadlock |
| provider adapters → keys | Each adapter holds an API key; key material must never leave the process or reach logs |
