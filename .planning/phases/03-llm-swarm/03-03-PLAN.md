<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scheduler → gateway timers | Bucket cool-down / daily-cap reset jobs in the cron registry; mis-firing risks premature recovery (rate-limit burn) or stuck buckets (verdict failure) |
| gateway → agent_telemetry | Operator reads bucket state from telemetry rows; stale/wrong status misleads the operator about pool health |
| gateway entry → env | Fail-fast on missing keys; partial key set must not start partial traffic |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-10 | Denial of service | Cooldown timer fires early (bucket recovers before 60s) | medium | mitigate | Registry job uses cooldownUntil timestamp; bucket.canFire() checks now >= cooldownUntil; clock integrity |
| T-03-11 | Info disclosure | Stale telemetry status misleads operator | low | mitigate | writeBucketState upserts on every transition; readBucketState returns latest row; status transitions tested |
| T-03-12 | Denial of service | Gateway starts with incomplete key set (partial traffic) | high | mitigate | parseEnv() fail-fast: GROQ_API_KEY + GITHUB_TOKEN required before LlmRouter constructs; process exits on missing |
| T-03-05 | Repudiation | Audit trail incomplete across scheduler + gateway | low | mitigate | router `path[]` + telemetry rows record every bucket/provider/model/status transition |
</threat_model>
