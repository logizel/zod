<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| candidate_url → fetch facade | Untrusted URL from poller enters fetch pipeline; SSRF risk to VM/internal services |
| env → Jina API | JINA_API_KEY crosses from env to Authorization header; leak risk in logs |
| PB filter → scratchpad | candidate_url interpolated into PB filter string; injection risk |
| browser → external site | Headless Chromium navigates to untrusted URLs; orphaned process risk |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering/Info disclosure | fetch() facade SSRF | high | mitigate | SSRF guard before any fetch: allow only http:/https:, refuse private/loopback/link-local ranges + localhost, refuse non-default ports except 80/443 |
