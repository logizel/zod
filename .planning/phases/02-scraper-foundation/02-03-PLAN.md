## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| candidate_url → fetch facade | Untrusted URL enters fetch pipeline; SSRF risk |
| env → Jina API | JINA_API_KEY crosses to Authorization header; leak risk |
| PB filter → scratchpad | candidate_url interpolated into PB filter; injection risk |
| browser → external site | Headless Chromium navigates to untrusted URLs; orphaned process risk |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering/Info disclosure | fetch() facade SSRF | high | mitigate | SSRF guard rejects private-range URLs before any fetch |
| T-02-02 | Info disclosure | JINA_API_KEY in logs | high | mitigate | pino REDACT_PATHS includes 'JINA_API_KEY' |
| T-02-03 | Tampering | PB filter injection via candidate_url | medium | mitigate | Single-quote escaping + unique index |
| T-02-04 | Denial of service | Orphaned Chromium processes | high | mitigate | ctx.close() in finally + RSS gauge + 24h soak drill |
